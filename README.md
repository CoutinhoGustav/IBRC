# IBRC — Igreja Batista Regular do Calvário do DF

> Repositório oficial de projetos digitais da **Igreja Batista Regular do Calvário do Distrito Federal**.

---

##  Estrutura do Repositório

Este repositório é organizado em três subprojetos independentes:

| Projeto | Descrição | Tecnologias |
|---|---|---|
| [`Site/`](./Site) | Site oficial da igreja | React · Vite · Tailwind CSS |
| [`Urna/`](./Urna) | Sistema de votação eletrônica | Vanilla HTML/CSS/JS · Next.js (v2) |
| [`Jogos/`](./Jogos) | Jogo da Velha com perguntas e respostas | HTML · CSS · JavaScript |

---

## 🌐 Site Oficial

O site institucional da IBRC, desenvolvido em **React + Vite**, disponível em:

🔗 **[https://ibrcdf.vercel.app/]**

---

## 🗳️ Urna Eletrônica

Sistema de votação digital para eleições internas da igreja, com suporte a múltiplas etapas, voto em branco e visualização de resultados. Disponível em duas versões:

- **Versão clássica** (`Urna/`) — HTML, CSS e JavaScript puro
- **Versão web moderna** (`Urna/urna-web/`) — Next.js + TypeScript + Tailwind CSS

---

##  Jogos

Jogo da Velha temático com perguntas e respostas, para uso em eventos e dinâmicas da Igreja.
